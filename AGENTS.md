
# Jarvis

## Vision

Jarvis is a personal AI Harness written in Go.

Its long-term goal is to assist with everyday tasks,
planning, reminders, personal knowledge, and
integrations with external services.

## Primary objective

This is a learning-first project.

The developer wants to deeply understand:
- Go programming
- Software architecture
- LLM internals and APIs
- AI agent orchestration
- Tool execution and MCP
- Persistent memory
- Background task scheduling

## Engineering principles

- Standard library first
- Minimal dependencies
- Explicit over implicit
- Simple before scalable
- Testable components
- Incremental development
- No premature abstractions

## Learning constraints

The human developer writes all production code.

AI assistance is restricted to:
- Teaching
- Architecture discussions
- Documentation guidance
- Debugging hints
- Code review
- Concept explanations

## Current architecture

Not decided yet.

Architecture should emerge progressively
from the implementation and learning process.
